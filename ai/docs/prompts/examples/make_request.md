이 자유 텍스트 요구사항을 `REQUEST.md` 형식으로 정리해줘.

규칙:
- 원문 의미를 유지할 것
- 추측으로 범위를 넓히지 말 것
- 꼭 필요한 정보만 질문할 것
- `Execution Path`는 `small-task`, `existing-code-change`, `new-feature-or-large-task` 중 하나로 판단할 것
- 내가 특정 backlog 항목을 붙인 경우에만 `FUTURE_REQUESTS.md` 내용을 참고할 것
- 기존 `REQUEST.md`에 내용이 있으면 `ai/workspace/backlog/request-archive/`에 먼저 아카이브할 것
