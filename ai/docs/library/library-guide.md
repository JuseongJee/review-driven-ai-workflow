# 라이브러리 안내

이 폴더는 평소 작업 시작용 프롬프트 모음이 아닙니다.

## 용도

- 특정 분석이나 검토를 별도 요청으로 시킬 때
- 공식 workflow 밖의 특수 상황을 다룰 때
- 아직 `prompts/`나 skill로 옮기지 않은 가이드를 둘 때

## 구분

- 평소 요청 예문과 보정 프롬프트는 `ai/docs/prompts/`에 둔다
- 이 폴더는 특수 상황용 보조 가이드
